## 🚀 Como Colocar no Ar (GitHub Pages em 3 Passos)

1. **Extraia o ZIP** em uma pasta no seu computador.
2. Crie um novo repositório no GitHub (ou use um existente) e faça o upload de todos os arquivos extraídos para a branch **main**.
3. No GitHub:
   - Vá em **Settings** > **Pages**
   - Em **Build and deployment > Source**, selecione **GitHub Actions**
   - Pronto! O workflow `.github/workflows/deploy.yml` incluído neste projeto fará a publicação automática do site em instantes.

## 💻 Como Rodar Localmente (Desenvolvimento)

```bash
# 1. Instalar as dependências
npm install

# 2. Iniciar servidor local
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador.
